## WayStation

A platform for applications, whatever language they are written in.

### Projects

| Repository | What it is | Stack |
| --- | --- | --- |
| [tasuki](https://github.com/way-station/tasuki) | An app for ekiden (relay running) teams: races, attendance, running orders, and lap times. MVP in progress | Go (chi), React + TypeScript, PostgreSQL, MongoDB |
| [Trabelle](https://github.com/way-station/Trabelle) | Share maps and travel itineraries with nothing but a phone | Go, TypeScript |
| [travel-prep-guide](https://github.com/way-station/travel-prep-guide) | Curated, practical pre-travel prep guidance as open data. Idea stage | — |
| [Traveling](https://github.com/way-station/Traveling) | A Flutter (Dart) sandbox | Flutter |

### How we work

- Design decisions are recorded as ADRs in each repository (`docs/adr/`)
- Issues and pull requests are written in English and Japanese
- Development runs in Dev Containers; no toolchains on the host
