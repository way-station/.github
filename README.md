## WayStation

A platform for applications, whatever language they are written in.

### Organizations

| Organization | What it holds |
| --- | --- |
| [way-station](https://github.com/way-station) | Application projects: tasuki, Trabelle, travel-prep-guide, Traveling, and private projects |

### Getting started

- Ask an enterprise owner for access to an organization or a private repository
- Install Docker and an editor only; development runs in Dev Containers
- Each repository's README explains how to run it

### How we work

- Design decisions are ADRs in each repository (`docs/adr/`). A new ADR is written as Accepted; its open pull request is the proposal
- Issues and pull requests are written in English and Japanese
- Large work uses a parent branch (`feature/...`); each step is a child pull request into it
